**Comparative Network Architecture Design Using Figma**
Using Figma or draw.io, create a comparative architectural diagram showing both a Cellular Wireless Network and a Mobile Ad Hoc Network (MANET) operating in the same smart city environment.

Analyze the architectures by comparing: 1.Infrastructure dependency. 2.Routing mechanisms. 3.Scalability. 4.Fault tolerance. 5.Mobility support. 6.Suitable application scenarios.

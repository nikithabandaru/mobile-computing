Figma-Based Mobile IP Communication Workflow Analysis
Design an interactive Figma prototype illustrating the complete workflow of Mobile IP communication when a Mobile Node moves from its Home Network to a Foreign Network. The design should include the Home Agent (HA), Foreign Agent (FA), Correspondent Node (CN), Care-of Address (CoA), Registration Process, and Packet Tunneling.

Analyze the communication process by identifying:

The purpose of each network component.
Points where packet delay or packet loss may occur.
The effect of node mobility on communication performance.
Possible improvements to reduce latency.
